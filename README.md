# Blue Anchor — website

Responsive multi-page site for [Blue Anchor](https://www.blueanchorjc.com), a waterfront seafood restaurant in Newport, Jersey City.

**Pages:** Home · Menu · Reservations · About Us · Gift Cards · The Captain's Club (Online Order opens the restaurant's Toast page).

No build step or frameworks — plain HTML, CSS and a little JS. Open `index.html` or deploy the folder as a static site (Vercel, Netlify, GitHub Pages).

See `README.txt` for how to add local photos, what's left to fill in, and the optional `build.py` page generator.
